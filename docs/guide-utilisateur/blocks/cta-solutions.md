# CTA Solutions

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Bannière **CTA Solutions** : titre, description et un bouton (lien ou formulaire HubSpot).

---

## À quoi sert ce bloc ?

Convertir le visiteur intéressé par une **solution** vers une démo ou une prise de contact.

---

## Quand utiliser ce bloc ?

- Bas de page Solutions.
- Après Key Features ou Why Choose Solutions.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Titre | Titre. | `[crochets]` optionnel. |
| Description | Texte. | 1 à 2 phrases, bénéfice + urgence douce. |
| Bouton — type | Lien ou formulaire HubSpot. | Formulaire pour « Demander une démo ». |
| Bouton | Libellé + destination. | Un seul CTA fort. |

---

## Exemple de contenu

- **Titre :** Prêt à **[sécuriser]** vos signalements ?  
- **Description :** Nos experts vous accompagnent du cadrage au déploiement.  
- **Bouton :** Demander une démo (formulaire)  

---

## Conseils de rédaction

- Message aligné avec la solution de la page.
- Éviter les CTA génériques (« Cliquez ici »).

---

## Points d'attention

- Formulaire HubSpot non sélectionné.
- Texte dupliqué du CTA Banner sur la même page sans raison.

---

## Résultat sur le site

Bandeau CTA avec **titre, texte et bouton** mis en avant.
