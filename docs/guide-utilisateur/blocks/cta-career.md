# CTA Career

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Bannière **recrutement** : titre, description et bouton CTA (lien vers offres ou formulaire HubSpot).

---

## À quoi sert ce bloc ?

Inciter les candidats à **consulter les postes** ou **postuler** / laisser leurs coordonnées.

---

## Quand utiliser ce bloc ?

- Page Carrières, À propos, fin d’article RH.
- Campagnes marque employeur.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Titre | Titre. | `[crochets]` sur un mot (aventure, équipe…). |
| Description | Texte. | Culture, mission, ce qu’on offre. |
| Bouton CTA — type | Lien ou formulaire. | Lien vers page offres ou formulaire spontané. |
| Bouton CTA | Libellé + cible. | Ex. « Voir nos offres », « Candidature spontanée ». |

---

## Exemple de contenu

- **Titre :** Rejoignez **[l'aventure]** Lumina  
- **Description :** Nous construisons une plateforme qui compte. Venez apporter vos talents.  
- **Bouton :** Voir les offres ouvertes  

---

## Conseils de rédaction

- Ton enthousiaste mais professionnel.
- Mentionner valeurs ou impact si une phrase le permet.
- CTA explicite (pas « En savoir plus » seul).

---

## Points d'attention

- Lien vers page offres obsolète.
- Ton incohérent avec la charte RH.
- Formulaire candidature non testé.

---

## Résultat sur le site

Bandeau **recrutement** avec message et bouton d’action.
