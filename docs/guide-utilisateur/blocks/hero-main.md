# Hero Main

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Grande bannière d’accueil en haut de page : badge, titre accrocheur, texte d’introduction, deux boutons d’action, chiffres clés, visuel produit (mockup) et encart de notification.

---

## À quoi sert ce bloc ?

C’est la **première section** que voit le visiteur sur la page d’accueil (ou une landing principale). Elle présente Lumina en une phrase, oriente vers l’action (démo, découverte) et renforce la crédibilité avec des statistiques.

---

## Quand utiliser ce bloc ?

- Page d’accueil du site.
- Landing page principale de campagne.
- Toute page où vous voulez un **impact fort dès l’arrivée** sur le site.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge Text | Petit texte au-dessus du titre (ex. nouveauté, catégorie). | 2 à 6 mots. Restez factuel et visible. |
| Title | Titre principal de la section. | 8 à 15 mots. Utilisez `[crochets]` pour mettre un mot en dégradé. |
| Description | Paragraphe sous le titre. | 2 à 4 phrases, bénéfice client clair. |
| Primary Button | Bouton principal (libellé + lien). | Ex. « Demander une démo ». Un seul objectif prioritaire. |
| Secondary Button | Bouton secondaire. | Ex. « Découvrir la solution ». Complète le bouton principal. |
| Stats | Liste de chiffres (valeur + libellé). | 2 à 4 stats max. Chiffres vérifiables (ex. 250+, 98 %). |
| Hero Mockup | Image du produit ou interface. | PNG/JPG net, fond transparent si possible. |
| Notification Text | Titre court dans l’encart sur l’image. | Une ligne, message concret. |
| Notification Subtitle | Sous-titre de l’encart. | Précision ou contexte (ex. délai, statut). |
| Resolution Rate | Texte chiffré affiché sur le visuel. | Ex. « 98 % » — doit correspondre à un message validé en interne. |

---

## Exemple de contenu

- **Badge :** Plateforme de signalement  
- **Title :** Bâtissez la **[confiance]** grâce au signalement sécurisé  
- **Description :** Lumina accompagne les organisations pour recueillir, traiter et suivre les alertes en toute confidentialité.  
- **Primary Button :** Demander une démo  
- **Secondary Button :** Voir les solutions  
- **Stats :** 250+ organisations · 98 % satisfaction · 24 h délai moyen  

---

## Conseils de rédaction

- Titre : court, orienté bénéfice, un seul mot en `[crochets]` si possible.
- Description : évitez le jargon ; parlez problème → solution.
- Boutons : verbes d’action (« Découvrir », « Demander », « Contacter »).
- Images mockup : haute résolution, lisible sur mobile.

---

## Points d'attention

- Titre trop long sur mobile.
- Statistiques non validées ou obsolètes.
- Mockup flou ou texte illisible dans l’image.
- Deux boutons avec le même objectif (confusion).
- Oublier la traduction des stats et boutons.

---

## Résultat sur le site

Le visiteur voit une **hero pleine largeur** : accroche, texte, deux boutons cliquables, chiffres de réassurance et une illustration produit avec un petit encart informatif.
