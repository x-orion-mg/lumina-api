# Flexible Platform - Be Agile

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section **plateforme flexible** : badge, titre, description, **carrousel de cartes** (icône, titre, texte) et texte d’aide au défilement.

---

## À quoi sert ce bloc ?

Montrer que la plateforme s’**adapte** à différents contextes, modules ou parcours via des cartes navigables.

---

## Quand utiliser ce bloc ?

- Page plateforme / produit.
- Message « agilité », modularité, évolutivité.
- Complément aux Features Tabs.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette. | Ex. « #Be Agile ». |
| Title | Titre. | `[crochets]` pour accent. |
| Description | Intro. | 2 phrases max. |
| Cards — Icon | Icône de carte. | Varier les icônes. |
| Cards — Title | Titre carte. | 3 à 6 mots. |
| Cards — Description | Texte carte. | 1 à 2 phrases. |
| Slider Hint | Texte sous le carrousel. | Ex. « Faites glisser ou utilisez les flèches » — adapter à la langue. |

---

## Exemple de contenu

- **Title :** Une plateforme **[flexible]** pour chaque organisation  
- **Carte :** Multi-sites — Gérez plusieurs entités depuis un même espace.  
- **Slider Hint :** Faites glisser pour voir les autres modules  

---

## Conseils de rédaction

- 4 à 6 cartes pour un carrousel équilibré.
- Ordre logique (parcours utilisateur).
- Hint de navigation : phrase courte, inclusive (souris + tactile).

---

## Points d'attention

- Une seule carte (carrousel inutile).
- Descriptions identiques entre cartes.
- Oublier de traduire le Slider Hint.

---

## Résultat sur le site

**Carrousel horizontal** de cartes avec flèches ou swipe ; texte d’aide en dessous.
