# Proof Section

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section **preuves** : badge, titre, description, bouton et **1 à 3 statistiques** (icône, valeur, suffixe, description).

---

## À quoi sert ce bloc ?

Combiner **message de conviction** et **chiffres clés** pour pousser à l’action (CTA).

---

## Quand utiliser ce bloc ?

- Milieu ou fin de page d’accueil.
- Avant bannière CTA finale.
- Renforcement après témoignages.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette. | Ex. « Impact ». |
| Title | Titre. | Orienté résultats. |
| Description | Texte. | Lien entre promesse et chiffres. |
| Button | CTA. | Ex. « Demander une démo ». |
| Stats — Icon | Icône. | Cohérente avec la stat. |
| Stats — Value | Chiffre principal. | Ex. 98, 250, 24. |
| Stats — Suffix | Unité ou symbole. | Ex. %, +, h. |
| Stats — Description | Libellé sous le chiffre. | Ex. « taux de satisfaction ». |

---

## Exemple de contenu

- **Title :** Des résultats **[mesurables]**  
- **Stat :** 98 % · Satisfaction client  
- **Button :** Voir nos références  

---

## Conseils de rédaction

- Chiffres **cohérents** avec Hero Main et About Stats.
- 3 stats maximum, impact visuel fort.
- Bouton = prochaine étape logique du parcours.

---

## Points d'attention

- Stats contradictoires entre blocs de la même page.
- Suffixe oublié (% manquant).
- Bouton sans destination.

---

## Résultat sur le site

Bloc texte + **compteurs visuels** + bouton d’action.
