# Testimonials - #Be Impactful

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section **témoignages clients** : tag, titre, description et sélection de **fiches témoignage** existantes.

---

## À quoi sert ce bloc ?

Afficher des **retours clients authentiques** (citation, nom, entreprise, photo) pour crédibiliser l’offre.

---

## Quand utiliser ce bloc ?

- Page d’accueil, Solutions, landing conversion.
- Après section preuves chiffrées.
- Pages sectorielles avec témoignages dédiés.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Tag | Étiquette. | Ex. « #Be Impactful ». |
| Title | Titre. | `[crochets]` optionnel. |
| Description | Intro. | 1 à 2 phrases invitant à lire les avis. |
| Testimonials | Fiches témoignage. | Créer d’abord les témoignages dans WordPress ; sélectionner 3 à 6 fiches publiées. |

---

## Exemple de contenu

- **Title :** Ils ont transformé leur **[culture]** du signalement  
- **Description :** Découvrez comment nos clients déploient Lumina au quotidien.  
- **Témoignages :** 3 fiches avec accord écrit des clients.  

---

## Conseils de rédaction

- Témoignages **courts**, spécifiques, avec bénéfice concret.
- Varier secteurs et tailles d’organisation si possible.
- Mettre à jour les fiches témoignage plutôt que dupliquer le bloc.

---

## Points d'attention

- Témoignage non publié ou brouillon.
- Citation trop longue (illisible sur mobile).
- Absence d’autorisation écrite du client cité.

---

## Résultat sur le site

**Carrousel ou grille** de cartes témoignage (photo, citation, auteur, entreprise).
