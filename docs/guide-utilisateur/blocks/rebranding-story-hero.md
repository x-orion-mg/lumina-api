# Rebranding Story Hero

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Hero **histoire du rebranding** : badge, titre, description, **points forts**, carte marque (dates, nom, label), **statistiques** et deux boutons.

---

## À quoi sert ce bloc ?

Raconter **l’évolution de la marque Lumina** (passé → aujourd’hui) de façon émotionnelle et factuelle.

---

## Quand utiliser ce bloc ?

- Page Rebranding, À propos, communiqué de marque.
- Lancement ou relance identité visuelle.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette. | Ex. « L'HISTOIRE DU REBRANDING ». |
| Titre | Titre principal. | `[crochets]` sur mot clé (renouveau, confiance…). |
| Description | Récit intro. | 2 à 4 phrases. |
| Points forts — Icône | Icône. | Jusqu’à 6 puces visuelles. |
| Points forts — Texte | Phrase courte. | Ex. « Nouvelle identité », « Même mission ». |
| Description carte | Sous-texte carte. | Ex. « depuis 2016 · réinventée en 2023 ». |
| Nouveau nom | Nom affiché. | Ex. « Lumina ». |
| Label carte | Étiquette carte. | Ex. « AUJOURD'HUI ». |
| Statistiques — Label | Libellé. | Ex. « Clients », « Pays ». |
| Statistiques — Valeur | Chiffre. | Validé marketing. |
| Boutons principal / secondaire | Type + lien ou formulaire. | Ex. « Découvrir » + « Contact presse ». |

---

## Exemple de contenu

- **Titre :** Une marque **[réinventée]**, une mission intacte  
- **Point fort :** Même engagement pour la confiance  
- **Stat :** 250+ · Organisations  

---

## Conseils de rédaction

- Cohérence avec Rebranding Timeline sur la même page.
- Chiffres et dates **exactes** (validation direction).
- Storytelling sincere, pas sur-promesse.

---

## Points d'attention

- Dates de rebranding incorrectes.
- Nom de marque incohérent (Lumina vs Lumina).
- Trop de points forts (6 max).

---

## Résultat sur le site

Hero riche avec **carte marque**, puces, stats et **deux CTA**.
