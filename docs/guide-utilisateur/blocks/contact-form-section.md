# Contact Form Section

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section **contact** : tag, titre, description, **formulaire HubSpot**, titres optionnels du formulaire, mentions légales.

---

## À quoi sert ce bloc ?

Permettre au visiteur de **vous contacter** directement depuis une page dédiée ou une section contact.

---

## Quand utiliser ce bloc ?

- Page Contact.
- Bas de page « Nous contacter » avec contexte éditorial au-dessus.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Tag | Étiquette. | Ex. « #Nous contacter ». |
| Titre | Titre. | `[crochets]` optionnel. |
| Description | Texte d’accueil. | Coordonnées, délais, ton accueillant. |
| Formulaire HubSpot | Formulaire. | Choisir le formulaire contact adapté à la langue. |
| Titre du formulaire (optionnel) | Sur-titre du bloc formulaire. | Si différent du titre principal. |
| Description du formulaire (optionnel) | Sous-titre formulaire. | Ex. champs obligatoires, délai de réponse. |
| Conditions / Mentions légales | Texte sous le formulaire. | Consentement, politique de confidentialité. |

---

## Exemple de contenu

- **Tag :** #Nous contacter  
- **Titre :** Une question ? **[Parlons-en]**  
- **Description :** Notre équipe vous répond du lundi au vendredi.  
- **Formulaire :** Contact général FR  

---

## Conseils de rédaction

- Indiquer **délai de réponse** réaliste.
- Lien vers politique de confidentialité dans les mentions.
- Tag et titre cohérents avec le reste du site.

---

## Points d'attention

- Formulaire dans la mauvaise langue.
- Mentions légales manquantes (RGPD).
- Description trop longue au-dessus du formulaire.

---

## Résultat sur le site

Bloc intro + **formulaire de contact** fonctionnel avec mentions en bas.
