# Human First

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section « Humain avant tout » : badge, titre, description, **cartes principales** (icône, titre, texte, couleur) et **éléments du bas** (icône + titre).

---

## À quoi sert ce bloc ?

Mettre l’**humain et l’écoute** au centre du discours : valeurs, approche relationnelle, piliers de la méthode Lumina.

---

## Quand utiliser ce bloc ?

- Page d’accueil ou À propos.
- Storytelling marque / RSE / culture d’entreprise.
- Complément à une section témoignages.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette de section. | Court (#Be Human, Valeurs…). |
| Title | Titre principal. | `[crochets]` pour accent. |
| Description | Texte d’introduction. | Ton chaleureux, 2 à 3 phrases. |
| Features — Icon | Icône de la carte. | Cohérente avec le message. |
| Features — Title | Titre de la carte. | 3 à 6 mots. |
| Features — Description | Texte de la carte. | Bénéfice humain concret. |
| Features — Gradient Color | Couleur d’accent (Orange, Purple, Blue). | Alterner pour variété visuelle. |
| Bottom Items — Icon | Icône du bandeau bas. | Simple, reconnaissable. |
| Bottom Items — Title | Libellé court. | Ex. « Écoute », « Protection », « Réponse ». |

---

## Exemple de contenu

- **Title :** Une approche **[humaine]** du signalement  
- **Feature :** Accompagnement — Chaque organisation est suivie par une équipe dédiée.  
- **Bottom item :** Réponse sous 48 h  

---

## Conseils de rédaction

- Privilégier émotions et confiance, sans pathos.
- Couleurs de cartes : alternance harmonieuse.
- 1 à 3 features + 1 à 3 bottom items (respecter les limites du bloc).

---

## Points d'attention

- Toutes les cartes en même couleur (monotone).
- Texte trop corporate, froid par rapport au titre « Human First ».
- Bottom items redondants avec les features.

---

## Résultat sur le site

Section en deux niveaux : **grandes cartes colorées** + **bandeau de points clés** avec icônes.
