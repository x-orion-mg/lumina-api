# Features Tabs

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section avec **onglets** : chaque onglet affiche un titre, une description, une liste de points, un bouton et une **image ou visuel**.

---

## À quoi sert ce bloc ?

Présenter **plusieurs fonctionnalités ou cas d’usage** sans surcharger la page : le visiteur navigue par onglets.

---

## Quand utiliser ce bloc ?

- Page produit / plateforme.
- Détail des modules (signalement, suivi, tableaux de bord…).
- Sections longues à decouper en thèmes.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette de section. | Ex. « Fonctionnalités ». |
| Title | Titre global. | `[crochets]` pour mot clé. |
| Description | Intro commune. | 1 à 2 phrases. |
| Tab Label | Nom de l’onglet. | 1 à 3 mots, visible dans la barre d’onglets. |
| Icon | Icône de l’onglet. | Lisible en petit format. |
| Content Title | Titre dans le panneau ouvert. | Complète le label de l’onglet. |
| Content Description | Texte du panneau. | 2 à 4 phrases max. |
| Features — Text | Puce / avantage. | Une idée par ligne, 3 à 6 puces. |
| Button | Lien d’action du panneau. | Ex. « En savoir plus » vers page dédiée. |
| Visual | Image du panneau. | Capture produit nette, ratio cohérent. |

---

## Exemple de contenu

- **Onglet :** Signalement  
- **Content Title :** Un canal simple pour vos équipes  
- **Features :** Interface multilingue · Anonymat · Accès 24/7  
- **Button :** Découvrir le module  

---

## Conseils de rédaction

- 3 à 5 onglets maximum pour la clarté.
- Labels d’onglets **distincts** et courts.
- Visuels différents par onglet (pas la même capture partout).

---

## Points d'attention

- Onglet sans image ou sans texte.
- Trop de puces (mur de texte).
- Libellés d’onglets trop longs (coupés sur mobile).

---

## Résultat sur le site

Barre d’**onglets cliquables** ; au clic, panneau avec texte, liste, bouton et visuel à droite ou en dessous.
