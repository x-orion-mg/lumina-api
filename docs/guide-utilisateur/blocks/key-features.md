# Key Features Solutions

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Liste de **fonctionnalités clés** sous un titre et une description (puces ou lignes, jusqu’à 10 éléments).

---

## À quoi sert ce bloc ?

Synthétiser **ce que la solution inclut** de façon rapide à parcourir (checklist de valeur).

---

## Quand utiliser ce bloc ?

- Pages Solutions.
- Après Hero Solutions ou Why Choose Solutions.
- Support commercial (argumentaire produit).

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Titre | Titre de section. | `[crochets]` optionnel. |
| Description | Intro. | 1 à 2 phrases. |
| Fonctionnalités — Texte | Une ligne par fonctionnalité. | Verbe ou nom clair ; pas de phrase entière si possible. |

---

## Exemple de contenu

- **Titre :** Tout ce dont vous avez **[besoin]**  
- **Description :** Une plateforme complète pour gérer le signalement de A à Z.  
- **Items :** Canal web sécurisé · Tableau de bord · Notifications · Export des données · Support dédié  

---

## Conseils de rédaction

- 5 à 8 items : lisible sans être exhaustif.
- Formulation parallèle (tous nominaux ou tous verbes).
- Du général au spécifique.

---

## Points d'attention

- Liste trop longue (>10 items tronqués ou illisibles).
- Doublons avec Features Tabs sur la même page.
- Formulations vagues (« Qualité », « Innovation »).

---

## Résultat sur le site

Bloc titre + **liste verticale** de fonctionnalités, style checklist ou puces.
