# Rebranding Timeline

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

**Frise chronologique** du rebranding : badge, titre, description, **étapes** (année, icône, titre, texte) et bouton.

---

## À quoi sert ce bloc ?

Montrer **pourquoi et comment** la marque a évolué, étape par étape dans le temps.

---

## Quand utiliser ce bloc ?

- Page Rebranding, sous Rebranding Story Hero.
- Narration historique produit ou marque.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Badge | Étiquette. | Ex. « POURQUOI CE REBRANDING ». |
| Titre | Titre. | `[crochets]` optionnel. |
| Description | Intro. | Contexte en 2 phrases. |
| Étapes — Année / Label | Date ou période. | Ex. « 2016 », « 2023 ». |
| Étapes — Icône | Visuel de l’étape. | Cohérent avec le message. |
| Étapes — Titre | Titre de l’étape. | Court. |
| Étapes — Description | Détail. | 1 à 3 phrases. |
| Bouton — type | Lien ou formulaire. | Ex. en savoir plus, contact. |
| Bouton | Libellé + cible. | Action de fin de parcours. |

---

## Exemple de contenu

- **Étape 2016 :** Création — Lancement de la première version de la plateforme.  
- **Étape 2023 :** Rebranding — Nouvelle identité pour refléter notre ambition internationale.  

---

## Conseils de rédaction

- Ordre **chronologique** strict.
- 3 à 5 étapes pour lisibilité.
- Alignement avec Story Hero (dates, messages).

---

## Points d'attention

- Timeline désordonnée (années incohérentes).
- Étapes vides ou dupliquées.
- Bouton final oublié.

---

## Résultat sur le site

**Frise verticale ou horizontale** avec repères dates et textes, plus bouton en bas.
