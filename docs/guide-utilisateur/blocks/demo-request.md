# Demo Request

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Section **demande de démo** : tag, titre, description, **cartes avantages**, titres du formulaire, **formulaire HubSpot** et conditions d’utilisation.

---

## À quoi sert ce bloc ?

Convaincre puis **collecter une demande de démo** via formulaire intégré, avec arguments clés à côté.

---

## Quand utiliser ce bloc ?

- Page « Demander une démo ».
- Landing campagne commerciale.
- Remplacement ou complément d’un CTA vers formulaire externe.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Tag | Étiquette. | Ex. « #Demander une démo ». |
| Titre | Titre. | `[crochets]` sur Lumina ou bénéfice. |
| Description | Intro. | Pourquoi demander une démo maintenant. |
| Cartes avantages — Icône | Icône. | Une par argument. |
| Cartes avantages — Texte | Argument court. | 1 phrase, orientée bénéfice. |
| Titre formulaire | Titre au-dessus du formulaire. | Ex. « Demander une démo ». |
| Description formulaire | Sous-titre formulaire. | Ex. « Réponse sous 24 h ». |
| Formulaire HubSpot | Formulaire à afficher. | Sélectionner le bon formulaire dans la liste. |
| Condition d'utilisation | Mentions légales / consentement. | Texte validé par juridique ; cases RGPD si applicable. |

---

## Exemple de contenu

- **Titre :** Pourquoi choisir **[Lumina]** ?  
- **Avantage :** Déploiement accompagné — Un expert dédié à chaque étape.  
- **Formulaire :** Demander une démo · Nous vous recontactons sous 24 h ouvrées.  

---

## Conseils de rédaction

- 3 à 4 cartes avantages max.
- Conditions claires et à jour (RGPD).
- Titre formulaire = action exacte attendue.

---

## Points d'attention

- Mauvais formulaire HubSpot (langue, champs).
- Conditions d’utilisation vides ou obsolètes.
- Promesse de délai (24 h) non tenue par les équipes commerciales.

---

## Résultat sur le site

Mise en page **deux colonnes** : arguments + **formulaire de contact** actif.
