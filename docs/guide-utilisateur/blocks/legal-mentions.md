# Mentions légales

## Aperçu du bloc

[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]

Page **mentions légales** : titre, description et **sections répétables** (titre + contenu riche).

---

## À quoi sert ce bloc ?

Afficher les **informations légales obligatoires** (éditeur, hébergeur, propriété intellectuelle…).

---

## Quand utiliser ce bloc ?

- Page « Mentions légales » du site.
- Mise à jour après changement d’éditeur, d’hébergeur ou de statut juridique.

---

## Champs à renseigner

| Champ | Description | Recommandation |
| ----- | ----------- | -------------- |
| Titre | Titre de page. | `[crochets]` optionnel. |
| Description | Intro ou date de MAJ. | Une ou deux phrases. |
| Sections — Titre de la section | Rubrique. | Ex. « Éditeur du site ». |
| Sections — Contenu | Texte formaté. | Texte validé juridique ; coordonnées exactes. |

---

## Exemple de contenu

- **Titre :** Mentions **[légales]**  
- **Section Éditeur :** Raison sociale, adresse, RCS, contact.  
- **Section Hébergeur :** Nom, adresse, contact de l’hébergeur.  

---

## Conseils de rédaction

- Reprendre le **modèle juridique** officiel de l’entreprise.
- Vérifier SIRET, adresse, directeur de publication.
- Une section = un thème (pas tout dans un seul bloc).

---

## Points d'attention

- Coordonnées entreprise incorrectes.
- Section oubliée (hébergeur, cookies, crédits).
- Contenu copié d’un autre site sans adaptation.

---

## Résultat sur le site

Page linéaire avec **titres de sections** et contenu formaté (paragraphes, listes, liens).
