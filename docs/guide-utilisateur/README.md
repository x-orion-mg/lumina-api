# Guide utilisateur — Blocs Lumina

Ce guide s’adresse aux équipes **marketing**, **communication**, **contenus** et **administrateurs** du site Lumina.

Il explique comment remplir chaque bloc disponible dans l’éditeur de pages WordPress (Gutenberg), sans vocabulaire technique.

---

## Captures d'écran dans les fiches

Chaque fiche contient un emplacement **[INSÉRER ICI UNE CAPTURE D'ÉCRAN DU BLOC]**.

Pour l’illustrer :

1. Ouvrez une page contenant le bloc dans WordPress.
2. Affichez la **prévisualisation** du bloc ou la page publiée.
3. Faites une capture d’écran et insérez-la à cet emplacement dans le document (PDF, Notion, etc.) si vous exportez le guide.

Dans l’éditeur, une **miniature de prévisualisation** du bloc est aussi visible lors de l’ajout du bloc dans la catégorie **Lumina**.

## Conseils communs à tous les blocs

### Mise en valeur d’un mot dans le titre

Sur de nombreux blocs, vous pouvez colorer un mot en **dégradé** en l’encadrant de **crochets** :

> Nous aidons les organisations à **[bâtir la confiance]**.

Sur le site, le mot entre crochets apparaîtra mis en avant visuellement (les crochets ne s’affichent pas).

### Boutons : deux types possibles

| Type | Usage |
|------|--------|
| **Lien / page** | Redirige vers une page du site ou une adresse web. |
| **Formulaire HubSpot** | Ouvre un formulaire de contact (démo, prise de contact, etc.). Choisissez le formulaire dans la liste proposée. |

### Contenus liés

Certains blocs vous demandent de **sélectionner des contenus déjà créés** sur le site (témoignages, partenaires, formulaires). Créez ou mettez à jour ces contenus dans le menu WordPress avant de les associer au bloc.

### Multilingue

Chaque langue du site possède sa propre version de la page. Reprenez la même structure de blocs et **adaptez les textes** pour chaque langue.

## Checklist générale avant publication

- [ ] Tous les champs obligatoires sont renseignés.
- [ ] Les textes ont été relus (orthographe, ton, cohérence de marque).
- [ ] Les liens et boutons ont été testés.
- [ ] Les images sont nettes et aux bonnes dimensions.
- [ ] La prévisualisation correspond au résultat attendu.
- [ ] Le contenu est disponible dans **toutes les langues** du site.
